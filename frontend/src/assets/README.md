# Sample label asset

`sample-label.png` is a generated, fictional granola package used only as a clearly labeled example and optional sample upload. It is not a real product or a measured model result.

Generated with the built-in ImageGen tool on 2026-11-10. Saved into this project at `frontend/src/assets/sample-label.png`. The sample's matching demonstration data is in `pages/home/sample.js`; real extraction of the sample still uses the backend.

## Generation prompt

Create one photorealistic premium product photograph for the homepage of a clean, professional food ingredient reader web app. This is a product-mockup image asset, NOT a website screenshot. Portrait 4:5 composition. A single matte ivory stand-up pouch of oat granola, back label facing the camera, upright, straight-on with very slight natural perspective, on a seamless light silver-grey studio background. The pouch fills 75% of the image height. Soft natural daylight from upper left, subtle realistic floor shadow, crisp paper texture, precise quiet industrial product photography. Back label has very clean black sans serif typography, generously spaced. Main heading exactly 'OAT & ALMOND GRANOLA'. Below a thin dividing rule, a legible ingredient section exactly 'INGREDIENTS' and 'Whole grain oats, almonds, honey, sunflower oil, sea salt.' A small simple black barcode near the bottom. No company names, no invented health claims, no colorful illustrations, no neon, no floating elements, no UI, no decorative objects. The emphasis is on a readable ingredient label and beautiful restrained materials. The lighting and background should be near-white cool neutral, not beige, tan or pink.
